# 管理端 API 接口文档

**基础路径**：`http://localhost:8080`

**通用响应格式**（`Result<T>`）：

```json
{
  "code": 200,       // 200=成功, 500=失败
  "message": "操作成功",
  "data": null       // 泛型数据，视接口而定
}
```

**认证方式**：

| 请求头 | 说明 |
|---|---|
| `Authorization: Bearer <token>` | 管理员登录后获得，`AdminLoginInterceptor` 校验 |

- token 存储于 Redis，退出登录时删除
- 拦截器自动补全缺失的 `Bearer ` 前缀
- **单设备登录**：同一账号只能在一台设备上登录，新设备登录会使旧设备的 token 失效，旧设备请求将返回 `{"code":401,"message":"账号已在其他设备登录"}`

**权限控制**：管理端 API 仅校验登录状态（JWT + Redis），不设细粒度权限控制。

## 1. 管理员认证 `/api/admin`

### POST `/api/admin/login` — 管理员登录

- **认证**：无需
- **请求体**：

```json
{
  "username": "admin (必填)",
  "password": "123456 (必填)"
}
```

- **响应**：`Result<String>` — `data` 为 JWT token

### POST `/api/admin/logout` — 退出登录

- **认证**：需登录
- **响应**：`Result<Void>` — `"退出成功"`

### POST `/api/admin/register` — 创建管理员

- **认证**：需登录（仅超级管理员可操作）
- **请求体**：

```json
{
  "username": "admin2 (必填)",
  "password": "123456 (必填)",
  "nickname": "管理员2 (可选)",
  "phone": "13800138000 (可选)",
  "email": "admin@test.com (可选)",
  "role": 2 (可选, 1=超级管理员/2=普通管理员, 不填默认普通管理员)
}
```

- **响应**：`Result<Void>` — `"创建成功"`

### GET `/api/admin/info` — 获取当前管理员信息

- **认证**：需登录
- **响应**：`Result<AdminVO>`

```json
{
  "id": 1,
  "username": "admin",
  "nickname": "超级管理员",
  "phone": "13800138000",
  "email": "admin@sportzone.com",
  "avatar": "https://...",
  "status": 1,
  "role": 1,
  "lastLoginTime": "2024-01-01 12:00",
  "lastLoginIp": "192.168.1.100",
  "createTime": "2024-01-01 12:00"
}
```

### PUT `/api/admin/info` — 更新管理员信息

- **认证**：需登录
- **请求体**：

```json
{
  "nickname": "新昵称 (可选, 3-20字符)",
  "phone": "13800138000 (可选)",
  "email": "new@test.com (可选)"
}
```

- **响应**：`Result<Void>` — `"更新成功"`

### PUT `/api/admin/{id}/info` — 超级管理员更新其他管理员信息

- **认证**：需登录（仅超级管理员可操作）
- **路径参数**：`id` — 目标管理员 ID
- **请求体**：全部可选，不传则不修改对应字段

```json
{
  "nickname": "新昵称 (可选, 3-20字符)",
  "phone": "13800138000 (可选)",
  "email": "new@test.com (可选)",
  "role": 2 (可选, 1=超级管理员/2=普通管理员, 不传则不修改)
}
```

- **说明**：超级管理员可修改其他管理员的昵称、手机号、邮箱及角色
- **角色修改限制**：
  - 不能修改自己的角色
  - 不能修改其他超级管理员的角色（仅可修改普通管理员）
- **响应**：`Result<Void>` — `"更新成功"`

### GET `/api/admin/list` — 管理员列表

- **认证**：需登录
- **响应**：`Result<List<AdminVO>>`

### PUT `/api/admin/password` — 修改密码

- **认证**：需登录
- **请求体**：
```json
{
  "oldPassword": "123456 (必填)",
  "newPassword": "newpass123 (必填, 至少6位)",
  "confirmPassword": "newpass123 (必填)"
}
```
- **说明**：改密成功后清除 Redis token，当前会话立即失效，需重新登录
- **响应**：`Result<Void>` — `"修改成功"`

### PUT `/api/admin/{id}/enable` — 启用管理员

- **认证**：需登录（仅超级管理员可操作）
- **路径参数**：`id` — 管理员 ID
- **说明**：将管理员状态设为正常（status=1），恢复登录权限
- **响应**：`Result<Void>` — `"启用成功"`

### PUT `/api/admin/{id}/disable` — 禁用管理员

- **认证**：需登录（仅超级管理员可操作）
- **路径参数**：`id` — 管理员 ID
- **说明**：将管理员状态设为禁用（status=0）；不可禁用当前登录账号；禁用后清除其 Redis token，已登录会话立即失效
- **响应**：`Result<Void>` — `"禁用成功"`

### PUT `/api/admin/{id}/password` — 重置管理员密码

- **认证**：需登录（仅超级管理员可操作）
- **路径参数**：`id` — 管理员 ID
- **说明**：将管理员密码重置为默认密码 `123456`；不可重置自己的密码；重置后清除其 Redis token，已登录会话立即失效
- **响应**：`Result<Void>` — `"重置成功"`

### DELETE `/api/admin/{id}` — 删除管理员

- **认证**：需登录（仅超级管理员可操作）
- **路径参数**：`id` — 要删除的管理员 ID
- **说明**：不可删除当前登录的管理员账号；删除后该管理员会话立即失效
- **响应**：`Result<Void>` — `"删除成功"`

### POST `/api/admin/avatar` — 上传头像

- **认证**：需登录
- **请求参数**：`file` (MultipartFile)
- **说明**：自动删除旧头像
- **响应**：`Result<String>` — `data` 为头像 URL

- **说明**：按 `sort_order` 升序排列，含所有未删除的分类

```json
[
  {
    "id": 1,
    "name": "篮球",
    "image": "https://sportzone-oss.oss-cn-shenzhen.aliyuncs.com/category/basketball.png",
    "icon": "basketball",
    "description": "篮球相关装备",
```

### GET `/api/admin/category/{id}` — 分类详情

- **路径参数**：`id` — 分类 ID
- **响应**：`Result<CategoryVO>`

### POST `/api/admin/category` — 创建分类

- **Content-Type**：`multipart/form-data`
- **请求体**：

| 字段 | 类型 | 位置 | 说明 |
|---|---|---|---|
| `category` | JSON 字符串 | `@RequestPart` | 分类数据 |
| `file` | 二进制文件 | `@RequestPart` | 分类图片（可选，支持 jpg/png/gif/webp） |

**category JSON 结构**：

```json
{
  "name": "足球 (必填)",
  "icon": "football (可选)",
  "description": "足球相关装备 (可选)",
  "sortOrder": 0 (可选, 默认0)
}
```

- **响应**：`Result<Void>` — `"创建成功"`

### PUT `/api/admin/category/{id}` — 更新分类

- **Content-Type**：`multipart/form-data`
- **请求体和字段规则同创建**（全部可选），上传新图片时自动删除旧图片
- **响应**：`Result<Void>` — `"更新成功"`

### DELETE `/api/admin/category/{id}` — 删除分类

- **路径参数**：`id` — 分类 ID
- **响应**：`Result<Void>` — `"删除成功"`

## 附录

### 统一响应码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 500 | 服务器内部错误 |

### 订单状态枚举

| status | 含义 | 如何进入 |
|---|---|---|
| 0 | 待付款 | 创建订单时 |
| 1 | 待发货 | 模拟支付（`PUT /api/order/{id}/pay`） |
| 2 | 运输中 | 管理端发货（`PUT /api/admin/order/ship`） |
| 3 | 待收货 | 运输中自动进入 |
| 4 | 待评价 | 确认收货（`PUT /api/order/{id}/confirm`） |
| 5 | 已完成 | 待评价后自动进入 |
| 6 | 已取消 | 取消订单 / 退款通过 |

### 退款状态枚举

| refundStatus | 含义 |
|---|---|
| 1 | 退款申请中 |
| 2 | 退款已通过 |
| 3 | 退款已拒绝 |

### 定时任务

| 任务 | 间隔 | 说明 |
|---|---|---|
| 自动确认送达 | 每 10 分钟 | 扫描 `status=2` 且 `deliveryTime` 超过 2 小时的订单，自动设为 `status=3`（待收货） |
| 每日数据统计 | 每天 00:05 | 统计前一天的新增用户/活跃用户/订单数/订单金额/支付金额/退款金额，写入 `sys_statistics_daily` |

### 全局异常处理

- `RuntimeException` → code=500, message=异常消息
- 参数校验异常（`MethodArgumentNotValidException`） → code=500, message=校验错误信息
- Controller 层无需 try-catch
