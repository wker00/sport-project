# SportZone 体育器材商城 — 用户端 API 接口文档

**基础路径**：`http://localhost:8080`

**通用响应格式**（`Result<T>`）：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

**认证方式**：

| 请求头 | 说明 |
|---|---|
| `Authorization: Bearer <token>` | 注册/登录后获得，`LoginInterceptor` 校验 |

- token 存储于 Redis，退出登录时删除
- 拦截器自动补全缺失的 `Bearer ` 前缀

**文件上传限制**：10MB（OSS 存储）

## 1. 用户管理 `/api/user`

### POST `/api/user/register` — 用户注册

- **认证**：无需
- **请求体**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | String | 是 | 用户名，最少3个字符，仅允许字母/数字/下划线/中文 |
| `password` | String | 是 | 密码 |
| `confirmPassword` | String | 是 | 确认密码，需与 password 一致 |

- **请求体示例**：

```json
{
  "username": "zhangsan",
  "password": "123456",
  "confirmPassword": "123456"
}
```

- **响应示例**：

```json
{
  "code": 200,
  "message": "注册成功",
  "data": null
}
```

### POST `/api/user/login` — 用户登录

- **认证**：无需
- **请求体**：

```json
{
```

|---|---|

| 400 | 请求参数错误 |

| 3 | 待收货 |
| 4 | 待评价 |
| 5 | 已完成 |
| 6 | 已取消 |

|---|---|

| status | 含义 |
|---|---|

### 全局异常处理

- `RuntimeException` → code=500, message=异常消息
- 参数校验异常（`MethodArgumentNotValidException`） → code=500, message=校验错误信息
- Controller 层无需 try-catch
