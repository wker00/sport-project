## 七、注意事项

1. **API 依赖：** 第 1-2 周部分功能（收藏、消息、验证码登录）需要后端新增对应接口，建议提前与后端沟通排期
2. **无测试基础设施：** 回归测试依赖人工走查，上线前务必完整走一遍核心流程
3. **持久化路径：** 修改 Pinia store 时注意 `persist.paths` 配置，确保 token 和 userInfo 不丢失
4. **部署环境：** 后端 API 地址通过 Vite 代理配置，生产环境需改为真实域名
